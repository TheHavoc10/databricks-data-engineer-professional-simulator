# Databricks Data Engineer Professional — Learning Campus

Sitio de preparación en español basado en la guía oficial de **9 de octubre de 2026**. Incluye 9 áreas, 45 objetivos, teoría avanzada, laboratorios, glosario, seguimiento y comparativas con Fabric. El simulador de preguntas se incorporará posteriormente.

## Primera publicación

Este repositorio tiene preparada una importación automática del ZIP del campus.

1. Descarga `databricks-data-engineer-professional-campus.zip` desde la conversación de ChatGPT.
2. En GitHub, abre **Add file → Upload files** y arrastra el ZIP **sin descomprimir** a la raíz de `main`. Guarda con **Commit changes**.
3. En **Settings → Pages → Build and deployment → Source**, selecciona **GitHub Actions**.
4. En **Actions**, comprueba el flujo **Publicar campus desde ZIP**. Si se inició antes de activar Pages, usa **Re-run jobs**.
5. El sitio se publicará en https://thehavoc10.github.io/databricks-data-engineer-professional-simulator/

El flujo extrae el ZIP, incorpora los archivos al repositorio y publica GitHub Pages. Después, los cambios a HTML/JS/CSS pueden desplegarse directamente por push.

## Privacidad

Las notas y el progreso se guardan en `localStorage` del navegador; no se sincronizan entre dispositivos. Haz copias desde **Estadísticas → Exportar JSON**.

Este es un recurso educativo independiente, no oficial ni afiliado a Databricks.
